# Readme
A simple fun julia code which finds the atmoshpheric pressure using ideal has law and force equilibrium

The theory and assumptions are dicussed in **height_pressure.md**

This repo contains multiple codes which evaluate the pressure using at different levels:
- **Pressure_Constant_g.jl**: Constant gravitational force (valid only neaar the durface)
- **Emperical_T.jl***: Assuming that the temperature exponentially decrease as height increase. 
- **Atmos_data.csv**: Contains refernce data about the actual pressures and temperature
